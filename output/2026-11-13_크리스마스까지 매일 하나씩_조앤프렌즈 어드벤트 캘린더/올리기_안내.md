# 인스타그램 올리기 안내 — 크리스마스까지 매일 하나씩

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `07.png` | 카드 7장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 — 그대로 복사해서 붙여넣기 |

카드 순서: 01 표지 → 02 고민 체크 → 03 어드벤트 캘린더란 → 04 구성 → 05 미니 10개 루틴별 → 06 사기 전 체크 → 07 정리

## 올리기 전 확인

- [ ] **출처**: 이번엔 뉴스 기사가 아니라 아모레몰 상품 페이지(2026-11-13 확인)가 출처예요.
- [ ] **가격**: 50,000원 → 45,000원 (11월 13일 표시가, 쿠폰 별도). 올리는 날 가격이 바뀌었는지 한 번 확인해 주세요.
- [ ] **이벤트**: 상세 페이지에 "아모레몰 11만원 이상 구매 시 6,900원", "포토후기 작성 시 본품 증정(10명), 11.09~11.29"가 있었어요. 조건이 복잡해서 카드엔 "직접 확인"으로만 적었어요.
- [ ] **5번 카드**: 미니 10개를 상자 순서가 아니라 종류별로 묶었어요 (카드에도 적어 두었어요).
- [ ] **협찬·광고 여부**: 제품을 협찬받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → **만들기 (+)** → **컴퓨터에서 선택**
2. `01.png` 클릭 → **Shift** 누른 채 `07.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5**
4. **다음** → **다음** → `caption.txt` 붙여넣기 → **공유하기**
