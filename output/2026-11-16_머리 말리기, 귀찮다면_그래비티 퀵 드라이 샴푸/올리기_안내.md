# 인스타그램 올리기 안내 — 머리 말리기, 귀찮다면?

## 이 폴더에 있는 것

| 파일 | 내용 |
|---|---|
| `01.png` ~ `07.png` | 카드 7장 (1080×1350, 세로 4:5) |
| `caption.txt` | 캡션 — 그대로 복사해서 붙여넣기 |

카드 순서: 01 표지 → 02 고민 체크 → 03 원리 → 04 어떤 제품 → 05 숫자 읽는 법 → 06 사용법 → 07 정리

## 올리기 전 확인

- [ ] **원리·시험 결과·품절 소식**: 장업신문·코스모닝 11월 12일 기사 기준이에요.
- [ ] **가격·사용법·향**: 그래비티 공식몰(2026-11-16 확인) 기준이에요. 공식몰은 오늘 "예약주문" 상태였어요.
- [ ] **1.9배**: 사람 머리가 아니라 모발 다발(인모 트레스) 시험에서, 드라이 2.5~5분 사이 겉물기 감소율을 비교한 결과예요. 기사엔 "건조 시간 절반 가까이 단축"이라는 표현도 있었지만, 과장으로 보일 수 있어 카드엔 쓰지 않았어요.
- [ ] **탈모 기능성**: 기사에 "탈모 증상 완화 기능성 보고" 내용이 있었지만, 의약품처럼 보일 수 있어 넣지 않았어요.
- [ ] **광고 여부**: 제품을 협찬받았다면 캡션 맨 앞에 `#광고`

## 올리는 방법 (PC)

1. instagram.com → **만들기 (+)** → **컴퓨터에서 선택**
2. `01.png` 클릭 → **Shift** 누른 채 `07.png` 클릭 → **열기**
3. 왼쪽 아래 **크기 조절 아이콘** → **4:5**
4. **다음** → **다음** → `caption.txt` 붙여넣기 → **공유하기**
